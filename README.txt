Toán 6 — bản tĩnh cho GitHub Pages

1. Giải nén ZIP này.
2. Tải các tệp bên trong ZIP lên thư mục gốc của repo GitHub: index.html, 404.html, thư mục assets/ và tệp README này.
3. Trong repo, mở Settings > Pages. Chọn Deploy from a branch, nhánh main và thư mục /(root).
4. Chờ GitHub Pages xuất bản trang.

Trang dùng JavaScript/CSS đã đóng gói sẵn, không gọi API hoặc máy chủ Replit. Bài học và tiến độ được lưu trong trình duyệt trên thiết bị hiện tại. Đường dẫn tương đối và điều hướng trong trang tương thích với URL GitHub Pages dạng /ten-repo/.
